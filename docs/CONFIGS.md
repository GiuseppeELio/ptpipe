# Case-file reference

Every run is described by one text file `comsol/configs/<case>.cfg` with lines `key = value` (comments after `#`).
The template is inferred from the keys: `shape` -> `PT_Particle`, `layers` -> `PT_Multilayer`, `A_abs` -> `PT_Device`.
Check a file before running it: `python -m ptpipe.case check <case>`; see what the references predict: `python -m ptpipe.case preview <case>`.

**Materials** (`material`, and every entry of `layers`):

- `Au`: analytic gold model (Etchegoin et al., J. Chem. Phys. 125, 164705 (2006)), ~300-1000 nm;
- `nk:materials/<file>.txt`: tabulated `lambda_nm n k`, e.g. from refractiveindex.info via `python -m ptpipe.rii search <material>` and `python -m ptpipe.rii fetch <shelf/book/nk/page>`; COMSOL and Python interpolate it linearly, constant extrapolation;
- a real number: non-absorbing refractive index.

Generated by `python -m ptpipe.case docs` from the SCHEMA in `ptpipe/case.py`: edit the schema, not this file.

## PT_Particle

| key | default | meaning |
|---|---|---|
| `tag` | - | case name, used for every output file |
| `shape` | sphere | sphere \| rod \| cluster |
| `material` | Au | Au \| nk:materials/<file> \| real index |
| `R_np` | 20 | sphere radius (nm) |
| `a_rod` | 40 | rod (prolate spheroid) semi-axis along x (nm) |
| `b_rod` | 10 | rod transverse semi-axis (nm) |
| `cluster_file` | - | comsol/clusters/<file>: x y z R (nm) per line (relative to comsol/) |
| `n_m` | 1.33 | refractive index of the embedding medium |
| `lams` | 450:10:700 | wavelengths (nm): a:step:b or a,b,c |
| `pols` | 1 | 1: k\|\|z E\|\|x, 2: k\|\|z E\|\|y, 3: k\|\|x E\|\|z |
| `lam_heat` | 530 | wavelength of the field maps and thermal run (nm) |
| `pol_heat` | 1 | polarization of the thermal run |
| `I_phys_Wcm2` | 100000.0 | intensity of the thermal run (W/cm2); results are linear in I |
| `k_med` | 0.6 | medium thermal conductivity W/(m K) |
| `rho_med` | 997 | medium density kg/m3 |
| `cp_med` | 4180 | medium heat capacity J/(kg K) |
| `k_np` | 314 | particle thermal conductivity (default Au) |
| `rho_np` | 19300 | particle density |
| `cp_np` | 129 | particle heat capacity |
| `h_np` | - | mesh size in the particles (nm); default R/4 (rod: b/4); <= gap/2 for clusters |
| `h_surf` | - | mesh size on the particle surfaces only (nm); use for small gaps with h_np ~ R/4 |
| `el_per_lambda` | 8 | mesh elements per wavelength in the medium (8 standard, 6 minimum, 12 convergence check) |
| `h_gap` | - | mesh size inside local spheres around each narrow gap (nm); set by ptpipe.mesh plan (gap/3) |
| `gap_ref` | - | gaps <= gap_ref (nm) get a gap sphere when h_gap is set; default R_min/2 |
| `gap_ball` | 1.5 | gap sphere radius = gap/2 + gap_ball*sqrt(R_eff*gap) (capped at 0.8 R_eff) |
| `hgrad` | 1.4 | maximum growth rate of the mesh (1.4 standard; 1.6 when memory is short) |
| `em_margin` | 0.35 | distance between the integration sphere and the PML, in units of lam_max/n_m |
| `pml_lambda` | 0.4 | PML thickness in units of lam_max/n_m |
| `R_th_factor` | 100 | thermal domain radius / outer PML radius |

|---|---|---|
